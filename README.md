## Saving Changes to GitHub With an AI Coding Agent

You do not need to type Git commands in a terminal. After you finish updating the website, ask your coding AI agent to review, commit, and push the changes for you.

### Before You Begin

- Make sure the project is connected to the correct GitHub repository.
- Make sure you are signed in to GitHub in your coding application.
- Save any files you edited.

### Recommended Prompt

Copy and paste this prompt into your AI coding agent:

> Review all changes in this website project. Do not change or delete any additional files. Summarize what changed and check for obvious errors. Then commit the current changes with a clear commit message and push the commit to the existing GitHub branch. Do not force-push. If GitHub needs permission or sign-in, ask me before continuing.

The agent should show you a summary, create a commit, and push it to GitHub. A **commit** saves a named version of your changes. A **push** uploads that saved version to GitHub.

### Prompt for a Specific Update

You can also describe the update in the prompt:

> Review the changes I made to the accomplishments and poster presentation sections. If everything looks correct, commit them with the message "Update accomplishments and poster presentations" and push the commit to the existing GitHub branch. Do not force-push or modify unrelated files.

### If the Agent Reports a Problem

- If asked to sign in, complete the GitHub sign-in and ask the agent to try the push again.
- If the agent reports a conflict, ask it to explain the conflict before allowing it to make changes.
- If the push is rejected, do not request a force-push. Ask the agent to safely check for newer GitHub changes first.
- If you are unsure about the files listed in the summary, stop and ask the agent to explain them before committing.

### Confirm the Upload

After the push succeeds, open the repository on GitHub and check that the newest commit and updated files appear there.
